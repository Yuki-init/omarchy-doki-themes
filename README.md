# Omarchy Doki Themes

88 [Omarchy](https://omarchy.org) themes generated from the
[Doki Theme](https://github.com/doki-theme/doki-master-theme) color definitions,
each with matching backgrounds, an icon theme and a preview.

## Install

```bash
git clone <this repo> ~/Projects/omarchy-doki-themes
cd ~/Projects/omarchy-doki-themes
./install.sh                 # copy every theme into ~/.config/omarchy/themes
./install.sh --link          # symlink instead, so edits here show up live
./install.sh doki-aqua doki-rem   # just the ones you want
```

Then pick one with `omarchy theme set doki-aqua` or the theme menu.

## Layout

```
themes/doki-<name>/
  colors.toml     Omarchy palette
  icons.theme     Yaru icon variant closest to the accent
  preview.png
  backgrounds/
scripts/gen_doki.py   regenerates colors.toml + icons.theme from doki-master-theme
```

## Regenerating colors

```bash
git clone --depth 1 https://github.com/doki-theme/doki-master-theme.git
./scripts/gen_doki.py doki-master-theme themes
```

The script maps each Doki definition onto Omarchy's palette slots, picks ANSI
colors by hue from the theme's own syntax colors, and nudges lightness until
they meet minimum contrast against the background. It also writes
`themes/doki-manifest.json`. Backgrounds and previews are not regenerated by it.
